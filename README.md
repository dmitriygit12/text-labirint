# УПП_РПО_24/4_4
# Project Goal
Движок и визуальный редактор для текстовых RPG-лабиринтов, позволяющий игрокам проходить лабиринты с ролевой системой, а авторам - создавать и проверять игровой мир без программирования
# Инструкция по запуску
1. Скопировать репозиторий
2. Открыть в Visual Studio 22 или новее .sln файл из корня
3. Запустить проект
